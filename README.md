# 铁律：图片重构为可编辑文档（通用，跨项目跨格式）

适用：截图/示意图/扫描页 → 可编辑文档（PPTX、DOCX、矢量图等任意原生目标）。

**总纲：先建关系库再动工；一切几何以源图像素取证为准；一切元素用目标格式原生对象；每次修改后渲染级双图比对全跑；测量工具先自证再采信；失败必实测归因；验证链未跑完不得宣称"完成/正确"。**

**违反以下任一条即视为错误交付，必须立即返工。**

## 一、开工前：建模

1. **关系库先行（宪法级）**：动工前对整图建元素关系库并落盘独立 JSON，每元素记类型（文字/框/形状/表格/插图/线条/箭头/点）、bbox、颜色、字号字体、层级，箭头记方向与两端落点坐标（起、止、头部形状）；全程画前查库→画后回写→纠错后更新（含根因与修正后几何）；排障先对照关系库，禁止脱离关系库逐像素考古。
2. **全图墨迹清零制**：第一步整图逐像素连通块提取，产出全量墨块清单，每块必须归入关系库某元素，无一漏账才算"图已读完"；禁止用局部走廊扫描证明"此处无墨/无元素"（抽查必有覆盖洞；案例：一条走廊未扫，某箭头上段整体缺失反复修不对）；"无元素"唯一依据=全图清单该区域零墨块。

## 二、取证（画之前）

3. **禁脑补**：禁止凭"见过类似图/风格记忆/这像XX"下任何结论，元素命名与归类也必须看图核实；感知可疑以数值证据裁决，"觉得像"不是证据。
4. **归属判定优先于形状判定**：小块墨迹禁止按长相定元素；判据：≥3点等距共线=虚线段、紧邻线条端点且指向一致=线条起端、真孤立才可独立成元素；归属不明默认并入邻近大结构整体矢量化，禁止把模糊墨迹"美化"成标准几何图元。
5. **判形三查**：①拟画矩形框前多行采样边框位置，坐标随行变化=弧线非框；②盒内"图标"先量内部墨迹密度（每行几像素且宽度渐变=笔触穿行非内容）；③箭头看翼缘张开/收敛与锥度（宽度峰→收敛到尖=箭头方向）；锥形笔触用双边缘闭合原生自由形状如实复刻，不硬凑等宽线+预设箭头。
6. **颜色逐元素实采**：文字/边框/笔触/中西文分别采样最暗像素取色。
7. **阈值逐元素标定+对账**：二值化阈值、最小墨块过滤、墨色下限均为逐元素变量，禁止全局套用；矢量化前实测该区域墨迹统计（最暗值/墨块数/尺寸）并留余量，矢量化后对账子形状数=实测墨块数，不等即有墨被吞，禁止带病放行（案例：过滤阈值吞掉5x6px点块，被误归因为"墨色浅"）。

## 三、生成：原生性

8. **零截图**：一切语义元素用目标格式原生对象（PPTX：文本框/预设形状/custGeom，其他格式同理）；截图仅限真正不可矢量化的位图内容且须用户明示认可。
9. **一元素一形状**：禁止多元素捆绑进同一形状/SVG（各元素独立对象、独立紧外接框、独立命名）；捆绑互相干涉错位且妨害编辑。
10. **禁擅自降级/自作主张**：任何替代方案（贴图、删元素、换形状、改位置、改落盘路径）先征得同意；用户明确的要求逐字执行，不得灵活变通。
11. **紧外接框**：自由形状的定位框紧贴自身墨迹，路径坐标相对框原点，禁止占满整页的大框妨害点选编辑。
12. **旋转先算视觉框**：旋转绕形状中心，旋转后视觉框≠声明框；预设形状比例固定，差异大改用自由形状。
13. **坐标换算单源**：px↔inch↔pt↔EMU 等全程一个换算函数；源图与渲染图尺寸不同先归一（两轴比例各自换算）；数组语义写明（[x,y,w,h] 解构错位曾产出159个垃圾形状）。

## 四、验证（每次修改后全跑，缺一不可）

14. **渲染双图比对**：改后立即渲染（目标文档→图片），与源图同尺寸并排人眼过图+分格差图；全图均值被白底稀释，禁止只报均值宣称接近。
15. **掩码差纯像素实现**：文字区涂白后比形状层；掩码用自写像素多边形，禁止依赖外部SVG合成（曾静默失败→两图同白→diff=0假全对）。
16. **像素差图+参数扫描**：|src−render|>阈值标红定位到坐标；艺术笔触区单独算meanAbs并对矢量化参数扫描取最优（分区域标定）。
17. **OCR回读**：渲染图再跑OCR，核对每条文本存在与中心坐标偏差。
18. **工具先自证**：测量工具输出不可能值（diff恒0、空输出、数量悬殊）先怀疑工具bug；关键工具用已知样例自测。
19. **结构自检≠视觉验证**：zip/元素计数/XML存在性只是门槛，绝不能作为"正确"证据（案例：XML全绿但矢量形状是空壳、渲染整块缺失）。

## 五、纠错纪律

20. **指正→先修测量→再修产物→复验归零**：人类指出差异后，第一动作是把比对工具升级到能自动暴露该类差异，第二动作才修产物，修完同工具复验。
21. **失败必实测归因**：描摹/渲染异常第一步回像素实测（采样色值、数墨块），禁止想象归因（"墨色浅/被切了"必须有色值证据）。
22. **每轮全量**：修一处也把第四节整链重跑，不许只验刚改的那块。
23. **诚实汇报**：只报实测数字与已验证事实；"完成/全对"只能在验证链全跑且热点收敛后说出；残留差异如实列出，不用形容词代替度量。

## 六、工具备忘（本项目实测踩坑，通用参考）

24. **OCR交叉验证**：@paddleocr/paddleocr-js PP-OCRv6 Small 为主（小字/中文显著强于tesseract），tesseract词框更紧作交叉验证；两引擎冲突回像素裁决（paddle会把邻近线条卷进文本poly、偶发大小写错）；浏览器SDK跑法：无头Chrome+CDP、import map补裸依赖、opencv本地UMD shim、ort本地bundle、evaluate前先Page.navigate；CDP独立端口；访问127.0.0.1前剥代理（NODE_USE_ENV_PROXY启动快照坑）。
25. **SVG/矢量化解析**：路径段终止条件只认M/Z（C/L混入会静默丢弃全部曲线段）；potrace npm版输出像素坐标无transform（与CLI不同）；fill-rule=evenodd时核对子路径绕向与包含关系。
26. **XML注入校验**：向OOXML注入形状后必查——标签栈配平、贝塞尔段数>0、cNvPr id无冲突、渲染后该区域墨迹像素>0。
27. **ImageMagick**：txt:-像素枚举恒16bit（/257）；-depth 8对txt:无效；crop语法WxH+X+Y（逗号格式静默产出整图）。
28. **禁止使用矢量字形替代文本**：图片重构中一切语义文字一律用目标格式原生文本对象（PPTX=文本框 a:t runs），禁止把文字描摹成矢量形状/一字符一图形/贴图。特殊字体不可得时按铁律29替换为微软雅黑并如实披露残差，不得以像素相似为由降级为形状（铁律8的custGeom许可是给图形元素的，不覆盖文字）。验收工具必须含"可编辑文本门禁"：文本区 a:t 内容精确匹配且零 custGeom 侵入。
29. **特殊字体一律替换为微软雅黑**：图片文本使用的是特殊字体（WPS 不支持/不可得）时，文本一律替换为微软雅黑（Microsoft YaHei）字体，不得用其他风格近似字体替代；字号/字距按微软雅黑实测重新调优。

**违反任一条即视为错误交付，必须立即返工。**
